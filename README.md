# 2652 Study Repository

A cumulative, unclassified study repository for the USMC Intelligence Data and
Software Engineer (NMOS 2652) training pipeline at Northern Virginia Community
College (NOVA). Use it to organize course material across cybersecurity,
databases, data engineering, scripting and programming, and applied intelligence
data workflows.

## Add a topic

1. Create a Markdown file under `topics/` named for the course and topic, for
   example `topics/databases/sql-joins.md`.
2. Copy the structure in [`templates/topic-template.md`](templates/topic-template.md).
3. Replace its placeholders using the supplied syllabus, notes, lab steps, code,
   or topic. Keep the four modules together in the topic file.
4. Add the date or week and course/module name in the tag at the top.

When source material is incomplete, distinguish known information from
assumptions, do not invent lab results or proprietary details, and ask concise
clarifying questions after providing what can be supported.

## Standard modules

Each topic file contains these sections in order:

1. **STUDY GUIDE** — core concepts, architecture or workflows, commands, practical
   applications, pitfalls, edge cases, and connections to related fields.
2. **CRAMSHEET** — a compact, one-page quick reference with key terms, relevant
   syntax, commands, ports/protocols or data structures, and must-know rules.
3. **FLASHCARDS** — 10–15 `Q: ... / A: ...` cards on definitions, commands,
   troubleshooting, and principles.
4. **PRACTICE QUIZ** — 8–10 mixed questions (multiple choice, command/output
   prediction, and scenarios), followed by an answer key with brief explanations.

## Information handling

Use only unclassified material. Do not add classified information, operational
details, credentials, or sensitive personal data. When examples are useful, use
generic or synthetic values and label them as examples.
